## 测试

### 默认的 `npm run e2e` 有 9 个用例失败（2026-10-23）

用各模块自己的配置（`tests/e2e/<模块>.config.ts`）运行全部通过；main 上同样如此，不是哪次改动引起的。原因在默认配置 `playwright.config.ts`：

- **在线版冒烟测试不该在这里跑**：顶层的 `testIgnore: ["static*.spec.ts"]` 被 chromium project 自己的 `testIgnore: ["i18n*.spec.ts"]` 覆盖（project 级设置替换顶层，不合并），
  于是 `static.spec.ts` 对着开发服务器跑了。它需要先构建、用静态服务器运行。
- **运行环境比模块配置紧**：默认 1280×720 视口、30 秒超时、按 CPU 核数并发；模块配置是 1440×900、60 秒、2 个 worker。
  - 画布 3 个超时：新建画布 → 拖入批注 → 连线 → 刷新后保留；画布与 PDF 角注双向同步；重复连线提示与调换方向。
  - 文字定位精度 3 个略超阈值：字形映射词框误差（0.10–0.11 em，要求 < 0.1）、术语下划线贴合（0.24 em）、贴着字母拖选校正差 1 个字符。
    推测是视口窄、页面缩放更小，像素取整折算成 em 更大，未验证。
  - 阅读器缩放后视口中心不跳：读不到当前页（`null.page`），疑与视口高度有关，未验证。
  - 批注卡片依次下推互不重叠：重叠 7 px（要求 < 1.5）。

建议的改法：chromium project 改用 1440×900、超时 60 秒，并在它的 `testIgnore` 里补上 `static*.spec.ts`；改完跑一遍默认配置，确认 9 个都通过，
再更新 CLAUDE.md 和开发文档 10.6 里的说明。

## 侧栏领域树（D15）

- 重命名中的领域被滚出可视区时，Firefox 下可能丢失输入。
- 把论文拖回它本来所在的领域仍显示可放置（实际不做任何事）。
- 拖动结束的兜底处理（结束后的第一次 `pointermove`）只在 Chromium 上验证过。
- 每一行都是一个 Tab 停靠点。
- 「全部」视图里不能拖到领域上归类（只能用右键菜单或编辑信息）。

## 术语导出为 acro（D16）

- 本机没有 TeX，导出的 `.tex` 没有实际编译过（属性名按 acro 3.8 源码核对）。有 TeX 时做一次 XeLaTeX 冒烟编译。
- 中文规范名、只有英文全称别名而没有缩写的术语，按"没有缩写"导出，英文全称丢失（可以放进 `foreign`）。
- 全小写的缩写（如 tf-idf）识别不出来，按"没有缩写"导出。

## 引用数（D17）

- 只有 OpenAlex 一个数据源；它没有收录的论文（部分中文期刊、会议）查不到。没有接 Semantic Scholar（需要申请 key）。
- 论文元数据里的作者常常为空或不准，按标题匹配时作者对不上就排除，对不上的同名论文可能漏掉或误配；不确定时可以在编辑信息里填 DOI。
- 预印本和正式版在 OpenAlex 里没有合并时，按 DOI 查到的是 DOI 对应的那个版本（可能是预印本，引用数偏少）；按标题匹配才会取正式版。
- 没有"导入后自动查询"的选项；以后可以在查询设置里加。
